# Orientation implementation contract

Read [the behaviour contract](ORIENTATION_PRODUCT.md) first. Source acquisition, immutable
analysis and presentation retain their existing seams.

Revision resolution continues through Git, without a second revision parser. Failed
resolution can inspect local shallow metadata and describe missing history. Keep cancellation,
resource limits, option termination and tag peeling. Trial history preparation uses only
local Git objects, preserves the pinned worktree/index, and is separate from application
capture (which never fetches).

A small message module owns text, dismissal identity and close controls. Both pages call
it rather than replacing entire message containers. One current dismissal is retained per
row, not an unbounded notification history. Source availability details remain factual.

CSS tokens define light/dark palettes. CSS system preference supplies the default; a tiny
head script restores only a valid explicit override before paint. A shared appearance
controller owns the selector and change notifications for canvas redraw. No dependency
or source analysis is added for themes.

Native summary views add the opaque workspace identity for local presentation preferences.
The existing native rectangles remain a compatible diagnostic projection. A browser scene
module builds a compact directory hierarchy from bounded file paths and projects an ordered
recursive partition. All canvas consumers share its rectangles. This is presentation state,
not inferred semantic structure or a change to captured identities. Compact unary paths,
limit drawn depth to ten levels, and virtualise the directory controls. Only bounded path/order/collapse
metadata is saved; storage denial keeps the current in-memory layout usable.

Projection/tree references stay stable until geometry changes; metadata-only refreshes
update tile facts without rebuilding directory controls. File admission is atomic: a
refused update cannot poison subsequent navigation. Auto-fit follows viewport resizing;
a manually moved camera preserves its world centre.

Default order is directories first, alphabetically within a parent. Manual order is local
to siblings. Persistence is per workspace, not snapshot or filename selection. Source/filter
requests still use native snapshot/file/version identities. Keep the current camera unless
layout changes require a refit; restore a historical camera only for the same layout revision.
