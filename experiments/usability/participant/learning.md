# Learn how source reaches the compiler

Use the supplied Vizzi learning workspace to trace how the Rust implementation of
lpc-rs obtains source, decides whether to retry a path with the c extension, and
reports a read failure.

Explain the behaviour in your own words. Cite the source and tests that support your
explanation, using file/declaration names or line references. Record anything you
cannot establish from the available views.

Work through the browser interface first. If you need another tool or help, record
what you wanted to do and where you became stuck before continuing. No project build
is required. Use the [notes sheet](notes.md) for answers and interaction observations.
